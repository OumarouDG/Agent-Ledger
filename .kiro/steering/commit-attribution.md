# Commit attribution

Use the human developer's configured Git identity for commits.
Do not add AI tools or assistants (including Kiro, Claude, Codex, or ChatGPT) as commit authors, committers, or co-authors.
Do not add Co-authored-by trailers or generated-by signatures crediting AI tools to commit messages or pull request descriptions.
Do not change Git author settings or rewrite existing commit history unless the user explicitly requests it.
Before committing, check the author identity and the complete commit message for unintended attribution.
